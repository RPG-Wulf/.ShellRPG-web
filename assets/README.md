# ShellRPG-www Assets

Diese Struktur trennt bewusst zwischen:
- `manifest/` fuer Spezifikation und Liefervertrag
- `environment/` fuer spaetere Topdown- und Birdseye-Umwelt-Assets
- `encounters/` fuer spaetere Birdseye-Encounter-Assets

Die erste Revision liefert die Manifest- und Prompt-Schicht. Die eigentlichen hochaufgeloesten Bildserien werden spaeter entlang dieser Struktur eingespeist.
